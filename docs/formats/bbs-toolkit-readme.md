# Birth by Sleep — український текст

## Швидко

1. Перекласти `text_all.txt` (українська пишеться **поверх** англійської).
2. Подвійний клік на **`Перевірити текст BBS.bat`** — чи все гаразд.
3. Подвійний клік на **`Запакувати текст BBS.bat`** — готові `.ctd` зʼявляться
   в `build\`, зі збереженням структури тек гри.

## Формат `text_all.txt`

```
### bbs_fourth.hed_out\original\message\en\event\rg\CTrg100.ctd
#12
This world is just too small.
#13
There, you see?
An empty world, like a prison.
```

**Не чіпати:** рядки `###` (шлях до файлу) і `#N` (номер запису у файлі).

Службові вставки лишати як є:

| вставка | що це |
|---|---|
| `{icon triangle}`, `{icon circle}`, `{icon square}`, `{icon cross}` | кнопки геймпада |
| `{icon l}`, `{icon r}`, `{icon analog}`, `{icon dpad}` | кнопки геймпада |
| `{color default}`, `{color white}`, `{color yellow}` | колір тексту |
| `{icon2 ..}`, `{icon3 ..}` | інші іконки |
| `{sjis 8140}` | двобайтовий символ, який не має однозначного відповідника |
| `{{` | сама фігурна дужка `{` |

Переносів рядків може бути скільки завгодно. Порожній рядок одразу після `#N`
означає порожній текст.

## Що вміє пакувальник

* бере оригінальний `.ctd` за основу — layout, ID і порядок записів
  зіпсувати неможливо;
* кодує текст у формат гри: ASCII напряму, латинська діакритика через
  сторінку `0x99`, пунктуація через `cp932`, **кирилиця через сторінку
  Shift-JIS `0x84`** (там вона й живе у справжньому Shift-JIS);
* перевіряє, чи є в шрифті гліф для кожного символа;
* перечитує зібраний файл і звіряє результат.

Помилки, які ловить:

```
#9999 немає в оригіналі              зіпсований номер запису
символ '😀' гра не вміє показати      поза межами Shift-JIS
у шрифті немає гліфа для 0x8970      кандзі, яких немає в англійському шрифті
                                     (такі рядки є і в оригіналі — це попередження)
```

## Інструменти (`tools\`)

| файл | що вміє |
|---|---|
| `bbsctd.py` | читання/запис `@CTD` версії 1 |
| `bbstext.py` | увесь текст в один `.txt` і назад, кодек тексту |
| `pack_bbs.py` | пакувальник, який запускає `.bat` |
| `arc.py` | читання контейнера `.arc` |
| `mtx.py` | PSP-текстури: розсвізлення, палітри |
| `font_ids.py` | ID усіх гліфів, наявних у `FontEn.arc` |

Перевитягти текст із гри:

```
tools\bbstext.py unpack "D:\...\Image\dt" text_all.txt        коротко
tools\bbstext.py unpack "D:\...\Image\dt" text_all.txt --all  усі 9705 записів
```

Детальний розбір форматів — у `ANALYSIS.md`.
