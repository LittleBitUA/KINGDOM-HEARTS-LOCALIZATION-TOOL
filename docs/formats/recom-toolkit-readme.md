# Re:Chain of Memories — українська: збірка й перевірка

## Що перекладати

**Тільки `text_ua.txt`** (це копія `text_uniq.txt` з уже вписаним тестовим набором).

`text_all.txt` перекладати **не треба**: у грі 30 503 повідомлення, але
унікальних рядків серед них лише **3 376** — ті самі таблиці реплік лежать
копіями в десятках тек `WORLD*`. Наприклад `Huh?` трапляється 96 разів,
«Something about this place is strange…» — 48.

`text_ua.txt` містить кожен рядок **один раз**. Під час збірки `packuniq`
сам розкладає переклад на всі входження — тобто роботи вдев'ятеро менше, і
неможливо забути якусь копію.

Номери `#N` — це позиції в детермінованому списку унікальних рядків. Окрема
таблиця відповідності не потрібна: збирач перебудовує той самий список.
**Номери `#N` і рядки `###` міняти не можна** — лише текст під ними.

Позначка `×48` біля номера — скільки разів цей рядок трапляється в грі.
Переклад автоматично лягає в усі ці місця. 3012 рядків із 3376 мають повтори;
рекордсмени: `Huh?` ×96, `Hoo-hoo-hoo-hoo!` ×88, репліки з Наміне ×48.

## Як зібрати

```
build.bat                    ← бере text_ua.txt
build.bat myfile.txt         ← бере вказаний файл
install.bat                  ← копіює build\ у гру, оригінали кладе в backup\
```

Угорі обох `.bat` — змінна `ROOT` зі шляхом до гри. Якщо гра стоїть в іншому
місці, виправ її там.

Потрібен Python 3 у `PATH` (перевір: `python --version`).

## Тестовий набір у цій збірці

Щоб одразу перевірити шрифти, українською перекладено **139 рядків**
(→ 501 входження у 426 файлах):

* **Інтерфейс (sysfont):** екран вибору режиму («Легкий / Звичайний /
  Складний / Екстремальний режим», описи режимів), налаштування вібрації та
  звуку, «Нова гра», «Продовжити», головне меню паузи (Огляд колод, Мапа
  світу, Стан, Щоденник, Налаштування), робота з колодами, типи карт,
  збереження й завантаження, «Так/Ні/Гаразд», «ІНФОРМАЦІЯ», «ЗАПИТАННЯ».
* **Діалоги (evtfont):** уся перша сцена в Замку Забуття — від «Ви двоє цілі?»
  до «Усе гаразд, чесно.» (рядки #1866–#1895).

Решта — англійська, як і було. Тобто в грі має бути видно **обидва** шрифти
поруч із латиницею: якщо кернінг чи розмір десь не той, це впаде в око одразу.
