# KH3D UA Toolkit

Набір інструментів для української локалізації
**Kingdom Hearts 3D: Dream Drop Distance HD** (Kingdom Hearts HD 2.8, PC).

Уміє дві речі:

1. **Шрифти** — додає в ігрові шрифти українську кирилицю так, щоб гра малювала
   її нативно, нічого не замінюючи.
2. **Текст** — витягує весь англійський текст гри в один `.txt`, а після
   перекладу пакує його назад у формат гри.

Усе вже зроблено й перевірено — шрифти лежать готові в `build\`, текст —
у `text_all.txt`. Лишається перекласти й запакувати.

---

## Швидкий старт

### 1. Поставити шрифти

Скопіювати вміст `build\kh3d_first\` поверх
`Image\dt\kh3d_first.hed_out\` у папці гри:

```
build\kh3d_first\original\font\en\bin\*.bcfnt                       (метрики + кирилиця)
build\kh3d_first\remastered\font\en\bin\<шрифт>.bcfnt\US_*.png      (текстури)
```

> **Потрібні обидві пари.** Сама текстура кирилицю не ввімкне — таблиця
> «Unicode → гліф» лежить у `.bcfnt`.

### 2. Перекласти текст

Відкрити `text_all.txt` у будь-якому редакторі (Блокнот теж підійде) і писати
українську **поверх** англійської:

```
### kh3d_first.hed_out\original\message\en\event\rg\bin\ctrg300.ctd
#8
Гей! Так ти цього хотів?
#11
Гей! Тепер пригадуєш, чи ні?..
```

**Не чіпати:**

| що | навіщо |
|---|---|
| `### …` | шлях до файлу гри |
| `#8` | номер повідомлення у файлі — по ньому переклад лягає на місце |
| `{PLAYER}`, `{BTN_A}`, `{STICK}`, `{U+E028}` | іконки кнопок і підстановки |

Номери йдуть з пропусками — це нормально. Порожні рядки, чисті числа й записи,
де крім службових вставок нічого немає, у файл не потрапляють: перекладати там
нічого, а в грі вони лишаються як були. З 7510 записів у `text_all.txt`
виведено **6059** справжніх рядків.

Решта правил:

* переносів рядків може бути скільки завгодно — ширину вікна задає гра,
  тому стеж, щоб рядок не вилазив за край;
* порожній рядок одразу після `#N` = порожній текст;
* `{{` означає саму фігурну дужку `{`;
* емодзі не працюють (гра вміє лише символи до U+FFFF).

### 3. Запакувати

Подвійний клік на **`Запакувати текст.bat`**.

Готові `.ctd` з'являться в
`build\kh3d_first\original\message\en\` — далі пакуй їх своїм способом
(KHPCPatchManager чи чим зручно).

**`Перевірити текст (без запису).bat`** робить те саме, але нічого не пише —
зручно, щоб просто переконатися, що переклад не поламаний.

## Що робить пакувальник

Оригінальний `.ctd` береться за основу, і в нього підставляється **лише текст**.
Розкладка вікон, ID і порядок записів беруться з оригіналу, тож зіпсувати
структуру через `.txt` неможливо. Після збірки кожен файл перечитується назад
і звіряється — якщо щось не збіглося, файл не записується.

Що ловить перед записом:

```
маркер #9999 немає в оригіналі            зіпсований або вигаданий номер
unknown tag {BTN_Z}                       помилка в службовій вставці
character '😀' is outside the BMP         емодзі гра не вміє
текст без маркера "#N" перед ним          з'їхав роздільник
немає оригіналу: …                        зіпсований рядок ###
```

BOM і CRLF від Windows-редакторів обробляються нормально.

Якщо треба інші шляхи:

```
tools\pack_ua.py --txt мій.txt --game "D:\...\Image\dt" --out куди\завгодно
```

`--dry` — не писати, лише перевірити. `--flat` — покласти всі файли однією
купою без підтек.

Перевитягти текст (напр. якщо треба геть усі записи, включно з порожніми):

```
tools\khtext.py unpack "D:\...\Image\dt" text_all.txt        коротко (за замовчуванням)
tools\khtext.py unpack "D:\...\Image\dt" text_all.txt --all  усі 7510 записів
tools\khtext.py unpack "D:\...\Image\dt" text_all.txt --ids  маркери @0xID замість #N
```

Пакувальник розуміє обидва види маркерів, тож старі файли теж зберуться.

## Шрифти

| шрифт | де видно | стиль | гліфів було → стало |
|---|---|---|---|
| `mesfont` | діалоги | біла заливка з чорним обведенням | 414 → 478 |
| `talkfont` | діалоги | те саме | 414 → 478 |
| `cmdfont` | команди в бою | білі, без обведення | 418 → 482 |
| `helpfont` | підказки, інтерфейс | білі, без обведення | 419 → 483 |

Додано 66 літер: `А-Я`, `а-я`, `Ґ Є І Ї ґ є і ї`. Апостроф `’`, лапки `« »`,
тире `—` і трикрапка `…` у грі вже були.

Гліфи намальовані з `ComicHearts-Regular.otf` (діалоги) і `KHMenu-Regular.otf`
(інтерфейс) — це ті самі шрифти, що в грі. Кегль, товщину обведення й базову
лінію підібрано попіксельним порівнянням з наявними англійськими гліфами.

Кирилиця лягла у **вільні комірки** аркуша — жоден англійський, японський
гліф чи іконку не замінено.

Перегенерувати:

```
tools\make_ua_font.py --orig "<гра>\original\font\en\bin" ^
                      --rem  "<гра>\remastered\font\en\bin" ^
                      --comic fonts\ComicHearts-Regular.otf ^
                      --menu  fonts\KHMenu-Regular.otf ^
                      --out   build_font
```

Перевірити, що гра побачить кирилицю:

```
tools\checkfont.py mesfont.bcfnt US_mesfont_bcfnt0.png
```

Подивитись, як виглядатиме (рендер один-в-один як у грі):

```
tools\preview.py mesfont.bcfnt US_mesfont_bcfnt0.png out.png "Текст" --zoom 2
```

## Технічні деталі форматів

### `.bcfnt` = BCFNT (CTR Binary Font, Nintendo 3DS)

Не PS2-формат. Метрики й таблиця символів — у `original/font/en/bin/*.bcfnt`,
HD-текстура — окремим PNG у `remastered/font/en/bin/<name>.bcfnt/US_*.png`
(рівно **2×** від оригінального аркуша).

Блоки: `CFNT` → `FINF` → `TGLP` → `CWDH` → `CMAP`

| блок | що містить |
|---|---|
| `FINF` | висота рядка, ascent, `alterCharIndex` (гліф-заглушка), зсуви на інші блоки |
| `TGLP` | розмір комірки, к-сть колонок/рядків, розмір аркуша, A4-текстура 3DS |
| `CWDH` | на кожен гліф: `left`, `glyphWidth`, `charWidth` (просування) |
| `CMAP` | Unicode → індекс гліфа; ланцюжок блоків 3 типів (direct / table / scan) |

**Координати гліфа не зберігаються списком** — обчислюються з індексу:

```
col = idx % nColumns
row = idx / nColumns
x = col * (cellWidth  + 1) + 1
y = row * (cellHeight + 1) + 1
```

| шрифт | комірка | колонок | оригінал | ремастер | рядків зайнято/всього |
|---|---|---|---|---|---|
| `mesfont` | 18×23 | 13 | 256×1024 | 512×2048 | 37 / 42 |
| `talkfont` | 18×23 | 13 | 256×1024 | 512×2048 | 37 / 42 |
| `cmdfont` | 11×13 | 10 | 128×1024 | 256×2048 | 49 / 73 |
| `helpfont` | 12×17 | 39 | 512×1024 | 1024×2048 | 13 / 56 |
| `numeral` | 6×8 | 4 | 32×256 | 64×512 (DDS) | 19 / 28 |

> **Пастка з `CMAP`.** Ланцюжок закінчується блоком `type 2 (scan)` із заявленим
> діапазоном **0x0000–0xFFFF**. Рушій зупиняється на першому блоці, чий діапазон
> містить код, тому будь-який блок, доданий ПІСЛЯ нього, недосяжний — і символ
> малюється як `alterCharIndex`, тобто `？`. Нові коди треба вмерджувати
> всередину цього catch-all блоку (і вставляти окремий блок ПЕРЕД ним).

> **Два стилі накреслення.** У `mesfont`/`talkfont` справжній HD-арт. А от
> «ремастер»-текстура `cmdfont`/`helpfont` — це просто оригінал, збільшений ×2
> методом nearest, тому для них малюємо в 1× і збільшуємо так само.

### `.ctd` = `@CTD` (CTR Text Data)

```
0x00  char[4]  "@CTD"
0x04  u32      version = 0x000001F7
0x08  u32      baseId
0x0C  u16      layoutCount
0x0E  u16      entryCount
0x10  u32      entryTableOffset   (0x20)
0x14  u32      layoutTableOffset
0x18  u32      textOffset
0x1C  u32      reserved

запис (8 байтів, таблиця вирівняна до 0x10):
0x00  u32  messageId
0x04  u16  textOffsetLow
0x06  u16  (layoutIndex << 4) | textPage
           адреса рядка = textOffsetLow + textPage * 0x10000

layout (20 байтів) — розміщення текстового вікна; для перекладу не чіпається
рядки — UTF-16LE, кожен завершується 0x0000, упаковані впритул
           0x000A          = перенос рядка
           U+E000..U+EFFF  = іконки / кнопки / підстановки
```

Стеля — **1 МіБ тексту на файл** (4-бітний номер сторінки × 64 КіБ).
Найбільший файл зараз 138 КБ, тобто запас ~7×. Довжину рядків міняти можна вільно.

Перевірено: всі 37 файлів (7510 рядків) розбираються й збираються
**побайтово ідентично** оригіналу.

### Де лежить текст

Увесь перекладний текст — це **37 файлів `.ctd`** у
`kh3d_first.hed_out\original\message\en\`. Перевірено:

* `kh3d_second.hed_out` — тексту немає взагалі;
* `kh3d_third.hed_out` — `event\en\**.exa` це `@EXA` скрипти подій (камера, дії,
  імена ассетів; тексту в них нема), `menu\en\**.ctt` — текстури, `.l2d` — розкладки;
* архіву `fourth` не існує (є `first`, `second`, `third` і `resources`).

Написи, вмальовані в текстури (`.ctt`) — клавіатура, заголовки хронік, іконки
світів — це окрема, графічна робота.

За даними з Ghidra (`FUN_1406d7f10`) гра обирає мову за індексом:
`0=jp, 1=uk, 2=gr, 3=fr, 4=sp, 5=it`, де `uk` — це United Kingdom, тобто
наша тека `en`. Саме її ми й правимо.

## Вміст архіву

```
Запакувати текст.bat                 запакувати переклад
Перевірити текст (без запису).bat    перевірити, нічого не пишучи

text_all.txt                         англійський текст, 6059 рядків для перекладу
README.md                            цей файл

build/kh3d_first/                    готові шрифти з кирилицею
fonts/                               вихідні .otf, з яких малюються гліфи
preview/                             як це виглядає
glyph_table.csv                      координати всіх гліфів чотирьох шрифтів
ua_glyphs.json                       детальна таблиця доданих гліфів

tools/
  khctd.py        читання/запис .ctd
  khtext.py       увесь текст гри в один .txt і назад
  pack_ua.py      пакувальник, який запускає .bat
  khfont.py       читання/запис .bcfnt + A4-текстури 3DS
  raster.py       растеризація гліфів (заливка + обведення)
  make_ua_font.py додати кирилицю у шрифт
  calibrate.py    підібрати кегль/обведення під інший шрифт
  checkfont.py    перевірити, чи гра побачить кирилицю
  preview.py      відрендерити рядок так само, як гра
```

Потрібен Python 3 — `.bat` знайде його сам.
Для скриптів роботи зі шрифтами додатково: `pip install pillow numpy fonttools scipy`.
Для роботи з текстом нічого стороннього не треба.
