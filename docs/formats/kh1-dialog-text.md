# KH1 (1.5 ReMIX PC) — діалоги подій (`EvMsg` .binl в ARD) і шрифт `kanji.knj`

Джерело: Ghidra, `KINGDOM HEARTS FINAL MIX.exe` — розкладка тексту діалогів `FUN_140171e80`
(звертається до таблиці ширин `DAT_142328b00`, завантаженої з `exchange/UK/kanji.knj` у
`FUN_140171b00`). Це **інший** інтерпретатор, ніж у тексту меню (див. `kh1-menu-text.md`).

## Байткод повідомлення (з коду)

| Байт | Довжина | Дія |
|---|---|---|
| `00` | — | кінець |
| `01` | 1 | пробіл (ширина `DAT_1404db4d8`) |
| `02` | 1 | новий рядок |
| `03`, `04` | 1 | маркери сторінки/очікування (`03` = пауза «натисни кнопку», `04` — з фіксацією позиції) |
| `05 lo hi` | 3 | u16 (тип/розмір вікна) |
| `06 lo hi` | 3 | u16 (швидкість відкриття) |
| `07 lo hi` | 3 | s16 (зсув; `hi = 0x80` → від'ємне) |
| `08` | 1 | прапорець (`local_198 = 1`) |
| `09 NN` | 2 | іконка кнопки: `NN < 200` — з таблиці ширин `DAT_1404d8fb8`, інакше спец-гліф (`FUN_14016f4b0`, наші `{Cross}` = `09 C8`…) |
| `0A 00 xx yy` / `0A NN` | 4 / 2 | міжрядковий інтервал (`yy + xx/10`; `0A 00 00 00` — типовий); з ненульовим 2-м байтом — 2 байти |
| `0B 00 lo hi`, `0B 01 lo hi`, `0B 10 lo hi` / `0B NN` | 4 / 2 | зсув X / абсолютний X / зсув; інакше 2 байти |
| `0C NN` | 2 | колір (`FF` = типовий вікна) — наші `{ColorRed}` = `0C 02` … |
| `0D 00 lo hi`, `0D 01 lo hi` / `0D NN` | 4 / 2 | швидкість виводу (`0x80/значення`) / масштаб; інакше 2 байти |
| `0E NN` | 2 | вставити змінну: `00` ім'я гравця, `01..07` предмет/магія/… (`{VarItem}` = `0E 01`), `10..17` число, `20..23` — з таблиці |
| `10`, `11` | 1 | режими (`local_198` = 5 / 6) |
| `12 lo hi` | 3 | u16 (позиція) |
| `18 NN` | 2 | гліф `(NN − 0x19)·256 + 0xE0` |
| `19..1F NN` | 2 | **двобайтовий гліф**: індекс `(b − 0x19)·256 + NN + 0xE0` |
| `≥ 20` | 1 | гліф: індекс `b − 0x20` |

Рядок, підставлений через `0E` (ім'я предмета тощо), розбирається вкладено з тими самими правилами.

## Шрифт діалогів `exchange/UK_kanji.knj` + HD-атласи

- `0x00000..0x40000` — PS2-бітмапа 2 bpp 1024×1024 (палітра 4 кольори на `0x40000`); на PC
  замість неї малюються `remastered/exchange/UK_kanji.knj/UK_kanji_knj{0,1}.dds` (1024×1024, BGRA8).
- `0x40080` — таблиця ширин, 1 байт на гліф (advance/2), **336 слотів** (21×16 комірок 48×64);
  ще 3 ідентичні копії на `0x401D0`, `0x40320`, `0x40470` (стилі/розміри).
- Індекс гліфа → комірка атласу: `col = idx % 21`, `row = idx / 21` (так само працює наш Kerning-режим).
- Зайнято: індекси 0–125, 140–220 (байти `0x20..0xFC`). **Вільно: 126–139 (байти `0x9E–0xAB`)
  і 221–335** — з них 224–335 адресуються лише двобайтовими кодами `19 00`…`19 6F` (112 гліфів).

## Що це означає для української

Кирилицю можна додати **нативно**, не жертвуючи латиницею: намалювати гліфи у вільні комірки
221–335 (`UK_kanji_knj0.dds`, ряди 10–15), прописати ширини в `.knj` (усі 4 копії) і кодувати
літери як `19 NN`. Рендерер це підтримує незалежно від мови (той самий код обробляє японські
`19 xx` у `FM_`-файлах). Ціна — по 2 байти на кожну «не-схожу» літеру (текст росте, але `.binl`
в ARD ми й так збираємо зі зсувом), і для `sysmsg.binl` треба зважати на буфер `0x4800`
(там меню-рендерер має ту саму схему `19 NN`, але вільні слоти лежать у таблиці
`exchange/US_font_data_tbl.bin` — 150 записів з `unicode = 0x3000`, зокрема байти `0xAA–0xC3`).
Поточний підхід (кирилиця на комірках акцентованої латиниці `0xC8+` через `ukrainian.json`)
лишається робочим — «нативний» варіант дає окремий набір кодів і автоматичну генерацію
гліфів із TTF, як у BBS (`bbsfont.py`).

## Генератор: `tools/py/kh1/kh1font.py` (вкладка «Шрифти UA» для KH1)

```
python tools/py/kh1/kh1font.py --knj original/exchange/UK_kanji.knj     --dds remastered/exchange/UK_kanji.knj/UK_kanji_knj0.dds     --font assets/fonts/ComicHearts-Regular.otf --layout game --out build/kh1_first.hed_out --preview preview.png
```

- Автокалібрування: розмір шрифту підбирається так, щоб заливка «H» мала висоту оригіналу
  (32 px), обводка й базова лінія — з оригінальних гліфів; заливка сіра `0x80`, обводка чорна.
- 66 літер → індекси 224–289 (`19 00`…`19 41`), ширини — у 4 копії таблиці; решта файлу байт-у-байт.
- `data/kh1_native.json` — та сама мапа для кодека (`scheme: 'native'`); детермінована: літера *i* → `19 i`.
- У застосунку: Налаштування → «Кирилиця у шрифті (KH1)» → «Нативна»; sysmsg.binl збирається
  гібридно (А В С Е Н І К М О Р Т Х а е і о р с у х — 1 байтом) через буфер `0x4800`.
- Kerning-режим показує гліфи 224+ як `#224 19 00 (А)` і рендерить превʼю з двобайтовими кодами.
