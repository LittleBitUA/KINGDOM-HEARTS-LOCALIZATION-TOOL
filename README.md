# Редактор тексту Kingdom Hearts 1 (Electron)

Сучасна версія редактора текстових файлів `.bin` / `.binl` / `.ard` гри
Kingdom Hearts 1, побудована на Electron з повною українською локалізацією
та візуальним стилем у синіх кольорах гри.

Логіка кодування/декодування байтів повністю відповідає оригінальному
C++/CLI редактору ([../Test/MyForm.h](../Test/MyForm.h)), а таблиця символів
взята з [../KH1SYS_Text.py](../KH1SYS_Text.py) і конвертована у JSON.

## Архітектура

```
electron-app/
├── main.js                    Main process: вікно, меню, IPC, файли
├── preload.js                 contextBridge → window.kh1
├── workers/
│   └── codec-worker.js        Worker Thread: encode/decode
├── shared/
│   └── codec.js               Спільний модуль кодування (без UI-залежностей)
├── data/
│   └── kh1sys_text.json       Таблиця байт → символ
└── renderer/
    ├── index.html             UI (без inline-скриптів)
    ├── styles.css             Тема Kingdom Hearts (сині кольори)
    └── renderer.js            UI-логіка, пошук, тости
```

**Безпека:** `contextIsolation: true`, `nodeIntegration: false`,
`sandbox: true`, CSP `default-src 'self'`. Renderer спілкується з main
тільки через `window.kh1.*`.

**Worker Thread:** main process тримає один екземпляр воркера, що обробляє
паралельні запити з кореляцією за `id`. Великі буфери передаються
через transferList без копіювання.

## Запуск (режим розробки)

```bash
cd electron-app
npm install
npm start
```

## Збірка `.exe` для Windows

Збирається через [electron-builder](https://www.electron.build/). Артефакти
з'являться в `electron-app/dist/`.

```bash
npm run build            # портативний .exe (один файл, без інсталятора)
npm run build:installer  # NSIS-інсталятор (з ярликами та вибором папки)
npm run build:all        # обидва варіанти одночасно
npm run pack             # розпакована збірка в dist/win-unpacked/ (для тестування)
```

Файли на виході:

- `dist/KH1-Text-Editor-2.0.0-portable.exe` — портативний, не потребує
  встановлення; запускається з будь-якої папки, дані тимчасово
  розпаковуються в `%TEMP%`.
- `dist/KH1-Text-Editor-2.0.0-setup.exe` — інсталятор з українським
  інтерфейсом, ярликами на робочому столі та в меню Пуск.

### Іконка (опціонально)

Якщо хочеш свою іконку — поклади `build/icon.ico` (256×256, multi-size ICO),
electron-builder підхопить її автоматично. Без іконки збірка пройде з
типовою іконкою Electron і попередженням у логах.

### Першу збірку

При першому запуску `npm run build` electron-builder завантажує бінарники
Electron для цільової платформи (~150 МБ) у кеш — наступні білди значно швидші.

## Можливості

- **Імпорт** `.bin/.binl/.ard` → байти декодуються у текст за таблицею
  KH1SYS_Text. Невідомі байти показуються як `{0xXX}`.
- **Експорт** редагованого тексту назад у бінарний файл. Підтримує
  спецтокени `{eol}`, `{lf}`, `{mX}`, `{゛b}` та сирі байти `{0xXX}`.
- **Пошук** (`Ctrl+F`), **знайти далі** (`F3`), з опцією врахування регістру.
- **Меню**: Файл / Редагування / Вигляд / Довідка — все українською.
- **Шорткати**: `Ctrl+O` (Імпорт), `Ctrl+S` (Експорт як), `Ctrl+F` (Пошук),
  `F3` (Знайти далі).
- **Статус-бар**: позиція курсора, розмір файлу.

## Сумісність кодеку з оригіналом

- Декодування: байт `0x00` (`{eol}`) додає `\n` після маркера для зручного
  редагування — так само, як у [MyForm.h:302-310](../Test/MyForm.h#L302-L310).
- Кодування: спочатку `\r\n`/`\r` → `\n`, потім `{eol}\n` → `{eol}`,
  далі будь-які `\n` → `{eol}`. Збігається з [MyForm.h:320-323](../Test/MyForm.h#L320-L323).
- Спочатку розпізнається літерал `{0xXX}`, потім жадібний пошук токенів
  з реверс-карти, відсортованої за довжиною (спадання). Колізії
  (`—` для `0x20` та `0xFA`, `-` для `0x64` та `0x6E`) детерміновано
  розв'язуються на користь меншого байта (стабільне сортування зберігає
  порядок вставки за зростанням ключа).
